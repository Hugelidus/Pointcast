In-browser Whisper spike (transformers.js + onnxruntime-web, no CDN)

To measure your GPU: run node dev/spikes/in-browser-whisper/server.mjs, open http://localhost:5531/ in Chrome, pick Device = webgpu, keep fp32 and click Run. Then pick wasm, 4 threads, and Run again to compare on the same machine. The first run downloads the model (about 290 MB for base fp32) into this page's cache.
Transcribes the repo's fixtures with word timestamps and scores them against the SAPI ground truth, exactly like dev/scripts/bench/transcribe.ts. Code is served locally; model weights download from huggingface.co once and are cached by this origin.
